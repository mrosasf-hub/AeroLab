# Diseño V2.3 · Aerolab Center

Esta edición conserva la lógica educativa de AeroPy V2.2, pero rehace la capa visual para acercarla al segundo concepto aprobado:

- Identidad visible de **Aerolab Center Creative Minds**.
- Sidebar profesional con Inicio, Ruta, Misiones, Laboratorio, Progreso, Logros y Configuración.
- Barra superior con búsqueda y perfil.
- Portada a pantalla completa con la imagen indicada por el proyecto en lugar del robot.
- Panel de progreso integrado en el hero.
- Botones de acción naranja/azul.
- Se eliminó el footer visible de AeroPy.
- Se eliminó la marca AeroPy de la navegación principal; el código interno y las claves de almacenamiento se conservan por compatibilidad.
- Responsive para escritorio, tablet y móvil.

El resto del sistema educativo se conserva: 60 misiones, 21 actividades especiales, prueba inicial, ruta adaptativa, repasos, editor CodeMirror, Pyodide, ejecución paso a paso, diccionario, laboratorio y progreso local.
